# 课题组网站 · 使用说明

本目录是一套完整的、可直接发布的课题组介绍网站，栏目结构参照北京大学雷晓光课题组网站（THE LEI GROUP）设计：

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 首页 | `index.html` | 课题组名称、标语、最新进展、研究方向、新闻与论文预览 |
| 导师介绍 | `professor.html` | 导师照片、联系方式、教育背景、任职经历、荣誉、研究兴趣 |
| 研究方向 | `research.html` | 各研究方向详细介绍与代表性成果 |
| 团队成员 | `members.html` | 教师 / 博士后 / 研究生 / 本科生 |
| 发表论文 | `publications.html` | 按年份分组的论文列表，可展开摘要 |
| 新闻动态 | `news.html` | 新闻与活动报道 |
| 组会与联系 | `contact.html` | 组会安排、招生信息、联系方式 |

---

## 一、如何替换为真实内容

目前所有内容均为“示例”，可直接用文本编辑器打开 HTML 文件修改。建议按以下顺序替换：

1. **全局替换名称**：把 `课题组名称`、`XXX Research Group`、`大学名称` 替换为真实信息（所有页面都会出现）。
2. **导师页**（`professor.html`）：
   - 把导师照片保存为 `images/professor.jpg`，替换 `professor.html` 中的占位图；
   - 填写真实的教育背景、任职经历、荣誉奖励与研究兴趣。
3. **研究方向页**（`research.html`）：将四个示例方向替换为真实方向，并配以具体介绍。
4. **成员页**（`members.html`）：替换名单；头像会自动显示姓名首字，如需真实照片，把照片放入 `images/` 并把 `.avatar` 换成 `<img>`。
5. **论文页**（`publications.html`）：按年份加入真实论文（作者、期刊、年份、DOI）。带“展开摘要”按钮的条目为可折叠摘要示例。
6. **新闻页**（`news.html`）：替换为真实新闻，可增删条目；日期写在 `.news-date` 中。
7. **联系方式**：`contact.html` 与每个页面底部的页脚都要更新为真实地址、邮箱、电话。

> 提示：论文中的 `*` 表示通讯作者；每个页面的底部页脚内容相同，请保持一致。

## 二、如何本地预览

直接用浏览器打开 `index.html` 即可（无需安装任何软件）。点击导航可浏览全部页面。

## 三、如何用 Sites 发布为在线网站

本网站为纯静态 HTML/CSS/JS，可直接作为 Sites 的素材：

1. 在 ChatGPT 桌面版选择 **Work** 或 **Codex**，在输入框中输入 `@Sites`，并附上以下提示（可直接复制）：

```
使用 @Sites 创建一个介绍课题组的网站：
- 我提供一整套现成的静态网站文件（HTML/CSS/JS），请原样导入并托管；
- 栏目包括：首页、导师介绍、研究方向、团队成员、发表论文、新闻动态、组会与联系；
- 网站面向学术同行、学生与潜在合作者，风格简洁专业，支持手机端访问；
- 先保存为可审阅版本，等我确认后再部署。
```

2. 把本目录中的全部文件上传或粘贴给 Sites。
3. 在预览中检查内容与排版，确认无误后选择“发布”，即可获得一个可公开访问的网址。

> 若你的账号尚未开通 Sites（Sites 需要 ChatGPT Work / Plus / Pro 且部分区域暂未开放），可先本地预览，或将这套文件部署到学校提供的服务器、GitHub Pages 等任意静态托管平台。
